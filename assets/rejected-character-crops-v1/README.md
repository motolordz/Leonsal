# Rejected Character Crops V1

These files were generated from JPEG infographic/contact sheets during the rejected 320-asset milestone.

They are preserved only for diagnosis and visual reference. They are not approved for runtime or production registry use because:

- they were cropped from composed chart sheets, not isolated source masters;
- they have opaque or sheet-derived backgrounds rather than real alpha transparency;
- some crops include labels, chart borders, percentage badges, neighbouring artwork, or excess sheet space;
- some source regions were too small for HD production delivery and were enlarged;
- the files are not verified as one clean character in one clean state.

Do not point production registries at this directory. Do not display these files in live games.
